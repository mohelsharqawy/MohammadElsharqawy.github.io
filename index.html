Research Interests

I am interested in efficient and sustainable computing systems for AI and machine learning, especially hardware-software co-design across compilers, runtimes, and architectures. I want to make generative-AI inference faster, more scalable, and more energy-efficient through context-aware optimization and memory-centric system design.

A complementary part of my work concerns system reliability and agentic SRE: translating real production incidents into high-fidelity failure scenarios and studying how LLM-based agents diagnose and mitigate faults in cloud-native systems.

My M.Sc. thesis examines another form of robustness: why diabetic-retinopathy models trained on one fundus imaging source degrade on another, and how representation learning can improve generalization without target-domain labels.

Open-Source Contributions

Three merged contributions to open systems-research infrastructure.

libCacheSim · High-performance cache library and simulator · Merged PR #318
MultiQueue cache-eviction algorithm

Implemented the MultiQueue (MQ) eviction algorithm in C from Zhou, Philbin, and Li's USENIX ATC 2001 paper. The implementation combines frequency-indexed LRU queues, time-based demotion, and a FIFO ghost buffer that preserves object frequency across evictions.

  • Added approximately 550 lines of implementation and tests to a simulator used by around 100 research institutions and companies.
  • Verified that MQ with one queue reproduces LRU exactly, including identical miss and byte-miss ratios.
  • Benchmarked MQ against FIFO, LRU, TwoQ, SLRU, ARC, SIEVE, and S3FIFO across multiple traces and cache sizes.

SREGym · System reliability and agentic SRE · Merged PR #774
GKE ran out of IP addresses

Reproduced a real GKE IP-exhaustion outage as a deterministic Kubernetes fault. The scenario uses Calico IPAM and strict affinity to exhaust an intentionally constrained address pool, leaving application pods stuck in ContainerCreating while an AI SRE agent diagnoses and mitigates the incident.

  • Designed the fault to trigger at runtime without cluster-wide reconfiguration.
  • Added repeatable setup and cleanup paths that restore cluster networking after each run.
  • Evaluated the Stratus agent and refined the mitigation to expose cross-namespace reasoning behavior.

SREGym · System reliability and agentic SRE · Merged PR #791
Feature-flag latent bug in the Hotel Reservation application

Modeled Fastly's 2021 global outage through a configuration flag that activates a dormant failure path. The /hotels endpoint returns HTTP 500 errors under load while every Kubernetes pod remains healthy, forcing the agent to connect a configuration change to a service-level failure.

  • Built the failure into a custom multi-architecture frontend image.
  • Implemented a reversible ConfigMap trigger and an HTTP-probe mitigation oracle.
  • Hardened the scenario through maintainer review for deterministic and auditable execution.
